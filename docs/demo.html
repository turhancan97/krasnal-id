Which Wrocław dwarf is this?

Wrocław is scattered with several hundred small bronze dwarf statues, individually sculpted but sharing a vocabulary — the same scale, the same material, the same crouching poses and props. Upload a photograph and this page will tell you which one it is, running the model in your own browser.

Why use location as a weight?

The research pipeline’s simulations found that restricting candidates to nearby statues helps less than random narrowing, because some lookalikes stand together; weighting by distance helps while keeping every statue eligible. These simulation results are separate from this identifier’s measured photograph-only accuracy.
