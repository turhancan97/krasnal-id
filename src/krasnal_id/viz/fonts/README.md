# Figure font

TeX Gyre Heros (regular, bold, italic): a free Helvetica-style sans from the GUST e-foundry,
unmodified, as distributed by CTAN at `fonts/tex-gyre/opentype/` (fetched 2026-11-05).

It is vendored so every publication figure renders in the same face on any machine, rather than in
whatever sans the host happens to have. It pairs with TeX Gyre Termes, the Times face the
short manuscript sets its text in.
